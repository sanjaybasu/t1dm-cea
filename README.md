# Cost-Effectiveness Analysis of Type 1 Diabetes Interventions in Low- and Middle-Income Countries

Analysis code for: Basu S, Zafra-Tanaka JH, Beran D. Cost-effectiveness of type 1 diabetes intervention clusters in low-income and middle-income countries: a systematic review and microsimulation analysis. *Lancet Diabetes Endocrinol* (in press).

## Methods

Patient-level discrete-time microsimulation model. Ten-year time horizon, monthly cycles, health system perspective. Costs in 2025 International Dollars (WHO-CHOICE methodology). Outcomes: QALYs and DALYs. Discount rate: 3% per year.

Intervention effectiveness derived from random-effects meta-analyses of 89 studies (20 734 participants). Cluster-level parameters estimated from Delphi expert consensus (n=15 experts, 2 rounds).

## Structure

```
src/model/          microsimulation model and parameters
src/analysis/       base case, sensitivity, and scenario analyses
src/utils/          cost-effectiveness calculations
src/visualization/  figure generation
results/            model outputs (generated by running analyses)
```

## Usage

```bash
pip install -r requirements.txt
python src/analysis/base_case_analysis.py
python src/analysis/sensitivity_analysis.py
```

Random seed: 42. Results reported per 1000 patients.

## Interventions

Individual: DSMES, CGM, SMBG, task-shifting, mHealth  
Clusters: integrated care delivery, technology-enhanced self-management, public-private partnership
